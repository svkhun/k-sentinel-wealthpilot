Two-Tier Low-Latency Architecture & Banking SLA

การออกแบบสถาปัตยกรรมระดับอุตสาหกรรมธนาคารเพื่อรองรับการประมวลผล Sub-80ms ในช่วง Payday Peak Concurrency

🏛️ การแยกชั้นประมวลผล 2 ระดับ (Two-Tier Design)

1 Tier 1: Offline/Nearline Graph Embeddings

ใช้ Relational Graph Convolutional Networks (RGCN) 16 มิติ วิเคราะห์ความสัมพันธ์ของเครือข่ายบัญชีม้า และแคชผลลัพธ์ไว้บน In-Memory Feature Store (Redis Simulation) สามารถดึงค่าได้ในระดับ O(1) Microseconds

2 Tier 2: Real-Time Pre-Transaction Inference

รวม Graph Embeddings เข้ากับ Telemetry สดของธุรกรรม (เวลาที่อยู่ในหน้าจอ, สัดส่วนยอดโอน, ปัจจัยยืนยันตัวตน) และประมวลผลผ่าน ONNX Runtime ก่อนยืนยันการโอนเงิน (Pre-Transaction Screening)
